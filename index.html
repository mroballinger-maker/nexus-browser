GOOD TO KNOW

A few quick
answers.

What does “early release” mean?＋

Nexus is a first Windows release. It has the core browser layout and customization, and we expect it to improve over time. Save important work before trying early software.

Does Nexus make me anonymous?＋

No. It does not include a VPN or promise anonymity or fingerprint resistance. Tracker blocking covers a small list of known domains, so it cannot block every tracker.

Will Windows show a security message?＋

The current build is unsigned, so Windows may show a SmartScreen or publisher notice. Only install it if you trust the source of the download.
